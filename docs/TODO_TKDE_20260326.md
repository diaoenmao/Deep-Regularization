## Phase 1: Fairness Control

### 1.1 Build a matched neural-only synthetic benchmark harness

Status: `next`

Goal:

- Compare only neural feature-selection methods under the same backbone and optimizer budget where possible.

Scope:

- Start on synthetic datasets only.
- Focus on neural methods that are realistic to control:
  - `SADMM-FS`
  - `LassoNet`
  - `CancelOut`
  - `DeepPINK`
  - `FSNet`
  - optionally `CAE`

Deliverables:

- one script for matched synthetic runs,
- one config block that defines shared backbone and training settings,

Rules:

- same train/test splits,
- same seeds,
- same backbone where the implementation allows it,
- same optimizer family where the implementation allows it,
- if a method cannot be matched cleanly, mark it explicitly as `not matched` rather than quietly mixing protocols.

## Phase 2: Method Simplification / Redesign

### 2.1 Implement a column-normalized scalar gate variant

Status: `next`

Motivation:

- keep the interpretable per-feature gate,
- reduce scale ambiguity between the gate and first-layer weights,
- make the gate variable easier to justify theoretically.

Target:

- preserve `g in R^m`,
- constrain or normalize first-layer columns so `g_j` better reflects feature amplitude,
- keep ADMM on the global gate vector.

Deliverables:

- new model variant in `custom_admm/src/`,
- minimal training integration,
- ablation against current SADMM-FS on synthetic tasks.

### 2.2 Decide the role of feature dropout

Status: `next`

Decision rule:

- If the new normalized-gate variant works without feature dropout, demote dropout to optional regularization.
- If dropout remains necessary, keep it but stop presenting it as a theoretically central component.

Deliverables:

- one ablation table:
  - with dropout,
  - without dropout,
  - under the same controlled setup.

### 2.3 Only if needed: try a column-group-sparse matrix gate

Status: `later`

Use only if scalar-gate normalization is not enough.

Constraint:

- do **not** implement an unconstrained full matrix gate for the main line.
- if matrix gating is explored, it must preserve a clean feature-level interpretation through column-group sparsity.

## Phase 3: Theory Support

### 3.1 Reframe the method theory around what is actually defensible

Status: `next`

Core theory should focus on:

- diagonal/global gate variable,
- linearized ADMM splitting,
- proximal sparsification,
- ratio norm vs `l1`,
- any identifiability benefit from column normalization.

Do **not** make feature dropout part of the core theoretical claim unless we can support it much better.

### 3.2 Build a source-backed theory note

Status: `next`

- what is already theoretically supported by our derivation,

- what remains an empirical heuristic.

Relevant lines to connect:

- stochastic gates / neural feature selection,
- dropout as regularization,
- adaptive group lasso / feature-selection consistency,
- nonconvex or linearized ADMM convergence.

Deliverable:

- one markdown note under `analysis/` summarizing the theory story we can honestly claim.
